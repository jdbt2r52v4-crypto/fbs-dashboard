Методика. Все данные — из API WB по токенам обоих кабинетов, только заказы со склада продавца. «Сборка и отгрузка» — API Маркетплейса: задание → скан поставки (или момент передачи, если скан ещё не проставлен). «Заказ → выкуп» — сопоставление отчётов заказов и продаж по идентификатору заказа. Отмены: время — из отчёта заказов (cancelDate), инициатор — из статусов заданий. Комиссия за скорость действует только для кабинета Крысина Я.П.
